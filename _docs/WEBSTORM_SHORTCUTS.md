# WEBSTORM SHORTCUTS (Personal Reference)

Это личная шпаргалка по горячим клавишам WebStorm, которые я использую в работе над проектом.  
Не является частью командных соглашений — сохранено для удобства и обучения.

## Основные действия

| Горячая клавиша     | Действие                 | Зачем нужно                                                  |
|---------------------|--------------------------|--------------------------------------------------------------|
| `Ctrl + Alt + L`    | Format Code              | Автоформатирование кода (включая JSON, SCSS, HTML)           |
| `Ctrl + Shift + F`  | Find in Path             | Поиск по всему проекту                                       |
| `Ctrl + N`          | Go to File               | Быстрый поиск файлов по названию                             |
| `Alt + 7`           | Structure                | Панель структуры файла — удобна для навигации по SCSS и HTML |
| `Ctrl + /`          | Comment / Uncomment Line | Закомментировать или раскомментировать строку                |

## Пример: форматирование JSON

1. Скопируй «сплошной» JSON (например, из `package.json`).
2. Вставь в новый `.json`-файл.
3. Нажми `Ctrl + Alt + L`.
4. → JSON станет читаемым с отступами!

Это особенно полезно при работе с API-ответами или конфигами.


## Работа с Git (без терминала)

| Горячая клавиша        | Действие                                      | Как это работает                                                             |
|------------------------|-----------------------------------------------|------------------------------------------------------------------------------|
| `Ctrl + K`             | Commit Changes                                | Открывает окно коммита: выбрать файлы, написать сообщение, нажать **Commit** |
| `Ctrl + Shift + K`     | Push                                          | Отправляет локальные коммиты в удалённый репозиторий                         |
| `Ctrl + T`             | Pull                                          | Получает изменения из удалённого репозитория                                 |
| `Alt + 9`              | Git Tool Window                               | Открывает полноценную панель Git: история, лог, сравнение, бранчи            |
| `Ctrl + D`             | Compare with Branch / Revision                | Сравнить текущий файл с версией в другой ветке или коммите                   |

## Советы по использованию

- После `Ctrl + K` (Commit) можно сразу нажать `Ctrl + Shift + K` (Push) — WebStorm предложит отправить.
- В окне коммита (`Ctrl + K`) можно:
    - галочками выбрать, какие файлы коммитить,
    - использовать ** Amend Commit **(изменить последний коммит), если ещё не пушил,
    - видеть **diff** прямо в том же окне.
- Все операции **автоматически отслеживают твой `origin`** (или другие remotes).
- Если есть конфликты при `Pull` — WebStorm откроет **визуальный мерж-инструмент**.

> Использование GUI-инструментов WebStorm для Git — не «читерство», а **профессиональный подход**: меньше ошибок, больше фокуса на коде.
