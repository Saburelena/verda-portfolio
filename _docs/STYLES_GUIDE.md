### src/styles/modern.scss — Современные фичи и доступность
| Селектор                                                               | Свойство                                  | Назначение                                                                                                                                                                                                      |
|------------------------------------------------------------------------|-------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `html`                                                                 | `height: 100%`                            | Делает `<html>` высотой во весь экран — нужно для «прижатого к низу» футера                                                                                                                                     |
| `html`                                                                 | `scrollbar-gutter: stable`                | Резервирует место под скроллбар → контент не прыгает, когда скролл появляется/исчезает                                                                                                                          |

| `@media (prefers-reduced-motion: reduce) { ... }` всё, что идёт внутри | `scroll-behavior: auto !important`        | Отключает плавную прокрутку для таких пользователей (auto — отключает плавную прокрутку, возвращает мгновенный переход (поведение по умолчанию), уважая настройку пользователя «уменьшить анимацию».            |

### src/styles/variables/_colors.scss — Глобальная цветовая система

Все цвета разделены на семантические группы для удобства поддержки, масштабирования и обеспечения визуальной целостности.
Использование переменных вместо «голых» HEX/RGBA-значений позволяет легко менять палитру без поиска по проекту.

#### Основные цвета (базовая палитра)
| Переменная         | Значение  | Назначение                                          |
|--------------------|-----------|-----------------------------------------------------|
| `$color-white`     | `#ffffff` | Чисто белый (текст, фоны, иконки)                   |
| `$color-black`     | `#000000` | Чисто чёрный (редко используется напрямую)          |
| `$color-dark-gray` | `#292b32` | Основной цвет текста, иконок, логотипа              |
| `$color-green`     | `#39aa5d` | Акцентный цвет (кнопки «Cart», статусы, интерактив) |
| `$color-body`      | `#f0f3f6` | Фон всей страницы и мобильного меню                 |


#### Дополнительные цвета (поддержка основной палитры)
| Переменная                    | Значение   | Назначение                                |
|-------------------------------|------------|-------------------------------------------|
| `$color-light-gray`           | `#dfe3e8`  | Светлые разделители, фоны карточек        |
| `$color-light-gray-secondary` | `#d2d8de`  | Более тёмный светло-серый (для контраста) |
| `$color-gray-text`            | `#8c9aac`  | Второстепенный текст (подписи, описания)  |
| `$color-green-hover`          | `#268644`  | Цвет акцентного элемента при наведении    |
| `$color-control-hover`        | `#282a30`  | Фон интерактивных элементов при наведении |


#### Прозрачные цвета (с альфа-каналом)
| Переменная                     | Значение                      | Назначение                                             |
|--------------------------------|-------------------------------|--------------------------------------------------------|
| `$color-border-header`         | `rgba(210, 216, 222, 100%)`   | Линия под хедером (тонкая, `0.4px`)                    |
| `$color-border-mobile-divider` | `rgba(11, 32, 63, 10%)`       | Разделитель в мобильном меню и рамка кнопки «Sign in»  |
| `$color-white-alpha-60`        | `rgba($color-white, 60%)`     | Полупрозрачный белый (фокус на тёмном фоне)            |
| `$color-black-alpha-30`        | `rgba($color-dark-gray, 30%)` | Тёмно-серый с прозрачностью (теневые эффекты)          |
| `$header-background`           | `rgba(242, 245, 248, 80%)`    | Полупрозрачный фон хедера с эффектом «матового стекла» |


#### Семантические цвета компонентов
| Переменная                    | Значение           | Назначение                                  |
|-------------------------------|--------------------|---------------------------------------------|
| `$logo-color`                 | `$color-dark-gray` | Цвет логотипа                               |
| `$menu-text-color`            | `$color-dark-gray` | Цвет текста в навигации (десктоп и мобилка) |
| `$register-button-text-color` | `$color-dark-gray` | Цвет текста кнопки «Sign in»                |
| `$cart-button-background`     | `$color-green`     | Фон кнопки «Cart»                           |
| `$cart-button-text-color`     | `$color-white`     | Цвет текста на кнопке «Cart»                |


#### Цвета для фокуса (доступность, keyboard navigation)
| Переменная                       | Значение                      | Назначение                                          |
|----------------------------------|-------------------------------|-----------------------------------------------------|
| `$focus-outline-color-primary`   | `rgba($color-green, 40%)`     | Фокус на основных CTA-элементах (например, «Cart»)  |
| `$focus-outline-color-secondary` | `rgba($color-dark-gray, 60%)` | Фокус на второстепенных элементах (ссылки, иконки)  |
| `$focus-outline-color-light`     | `$color-white-alpha-60`       | Фокус на тёмных поверхностях (контраст сохраняется) |

##### Ключевые принципы системы:
- **Семантические названия:** переменные описывают назначение, а не оттенок (`$menu-text-color`, а не `$gray-900`).
- **Прозрачность через %:** все alpha-значения записаны в процентах (требование Stylelint).
- **Наследование:** многие цвета построены на базовых (`$color-white-alpha-60` использует `$color-white`).
- **Доступность:** все фокус-цвета имеют достаточный контраст при 30–60% прозрачности.

### src/styles/media.scss — Медиа-миксины

#### «От и выше» — стили применяются **на этом размере и крупнее**

### src/styles/mixins.scss — Универсальные миксины
Многоразовые миксины для типографики, фокуса, сбросов, выравнивания и интерактива.

#### Типографика
| Миксин                   | Поведение / Влияние на UI                                                                                    |
|--------------------------|--------------------------------------------------------------------------------------------------------------|
| `fluid-text($min, $max)` | Создаёт плавно масштабируемый шрифт с помощью `clamp()` — от `$min` до `$max` в зависимости от ширины экрана |

#### Сбросы
| Миксин         | Поведение / Влияние на UI                                                             |
|----------------|---------------------------------------------------------------------------------------|
| `reset-link`   | Делает ссылку визуально нейтральной: убирает подчёркивание, наследует цвет текста     |
| `reset-button` | Превращает кнопку в «чистый холст»: без фона, границ, padding, с наследованием шрифта |

#### Позиционирование и выравнивание
| Миксин        | Поведение / Влияние на UI                                                  |
|---------------|----------------------------------------------------------------------------|
| `flex-center` | Центрирует содержимое по горизонтали и вертикали с помощью Flexbox         |

#### Интерактив
| Миксин                  | Поведение / Влияние на UI                                                |
|-------------------------|--------------------------------------------------------------------------|
| `hover`                 | Обеспечивает корректный отклик на наведение (desktop) и нажатие (touch)  |
| `press-down($offset)`   | Создаёт тактильный эффект «нажатия»: элемент смещается вниз на `$offset` |
| `focus-outline-rounded` | Добавляет единый, закруглённый фокус-контур при навигации с клавиатуры   |

#### Кнопки
| Миксин        | Поведение / Влияние на UI                                                                             |
|---------------|-------------------------------------------------------------------------------------------------------|
| `button-base` | Задаёт единый внешний вид и поведение для всех CTA-кнопок: высота, padding, закругление, фокус, сброс |

### src/styles/utilities.scss — Вспомогательные классы
Набор утилитарных классов для **крайних случаев**, когда семантическая разметка недостаточна.  
Используются **редко и целенаправленно**.

| Класс              | Поведение / Влияние на UI                                                                              |
|--------------------|--------------------------------------------------------------------------------------------------------|
| `.visually-hidden` | Полностью скрывает элемент визуально, но оставляет доступным для скринридеров и клавиатурной навигации |
| `.visible-mobile`  | Показывает элемент **только на мобильных устройствах** (до 767px), скрывая на планшетах и десктопах    |
| `.u-hidden-mobile` | Скрывает элемент **только на мобильных устройствах**, оставляя видимым на планшетах и десктопах        |
| `.min-content`     | Устанавливает ширину по самому длинному слову                                                          |
| `.fit-content`     | Устанавливает ширину по контенту с переносами + защита от переполнения на мобильных                    |
| `.badge`           | Готовый стиль для компактных бейджей (ширина по контенту, padding, скругление)                         |
> Утилиты — **исключение**, а не правило. Основная стилизация должна быть компонентной.

### src/styles/variables/_index.scss — Точка сбора переменных
Этот файл объединяет все файлы переменных в одну удобную точку подключения.
Благодаря ему в других SCSS-файлах можно писать:
`@use "variables"; // вместо отдельного импорта каждого файла`

`$mobile`

Это технический файл-агрегатор, а не источник данных.
Все значения задокументированы в исходных файлах (_colors.scss, _breakpoints.scss и др.).
