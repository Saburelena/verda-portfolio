# CSS PROPERTIES DICTIONARY

Полный перечень CSS-свойств, используемых в проекте.  
Для каждого — общее значение, цель в проекте и примеры использования.

## Текст, списки и оформление

| Свойство          | Общее значение                                                       | Зачем в проекте                                                    | Где используется                                                 |
|-------------------|----------------------------------------------------------------------|--------------------------------------------------------------------|------------------------------------------------------------------|
| `text-decoration` | Определяет декоративные линии под/над текстом (обычно подчёркивание) | Убирает подчёркивание у ссылок для чистого визуального вида        | `_header-nav-item`, `_mobile-nav-link` (через `reset-link`)      |
| `border`          | Задаёт границу элемента (ширина, стиль, цвет)                        | Добавляет разделитель под хедером и рамку у мобильной кнопки входа | `.header { border-bottom }`, `.header__mobile-signin { border }` |
| `list-style`      | Управляет маркерами маркированных и нумерованных списков             | Убирает стандартные точки у кастомных списков                      | `.header__menu-list`, `.header__mobile-nav-list`                 |
| `flex-shrink`     | Определяет, может ли элемент сжиматься в flex-контейнере             | Гарантирует, что иконка не сожмётся при нехватке места             | `.header-signin-shared__icon`                                    |


## Гибкая типографика и размеры

| Свойство / Функция           | Общее значение                                                                              | Зачем в проекте                                                                                                                          | Где используется                                             |
|------------------------------|---------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------|
| `clamp(min, preferred, max)` | Устанавливает значение, которое плавно изменяется между min и max в зависимости от viewport | Реализует плавную адаптивную типографику без скачков                                                                                     | `mixins/fluid`, `globals.scss` (заголовки, базовый шрифт)    |
| `font-size`                  | Указывает размер шрифта                                                                     | Контроль читаемости на всех устройствах                                                                                                  | Везде, особенно в `globals.scss`                             |
| `line-height`                | Задаёт межстрочный интервал                                                                 | Улучшает читаемость и визуальный ритм текста                                                                                             | `globals.scss`, `modern.scss` (унифицированное значение 1.5) |
| `font-weight`                | Задаёт насыщенность шрифта                                                                  | Создаёт иерархию (medium для заголовков и кнопок)                                                                                        | `variables/_typography.scss`, компоненты                     |
| `text-wrap: balance`         | Балансирует длину строк в многострочных заголовках                                          | Улучшает визуальное восприятие, особенно на средних экранах (700–900px), где заголовки часто разбиваются на 2–3 строки с неравной длиной | `globals.scss` (все `h1–h4`, `.h1–.h4`)                      |
| `system-ui`                  | Использует нативный шрифт операционной системы                                              | Гарантирует современный и «родной» вид текста, даже если кастомный шрифт не загрузился                                                   | `variables/_typography.scss`                                 |


## Отступы и размеры (логические свойства)

| Свойство           | Общее значение                                                     | Зачем в проекте                                                        | Где используется                   |
|--------------------|--------------------------------------------------------------------|------------------------------------------------------------------------|------------------------------------|
| `margin-block-end` | Отступ в конце блочного направления (обычно «снизу»)               | Логическое свойство, корректно работает при смене `writing-mode` и RTL | `globals.scss` (параграфы)         |
| `margin-inline`    | Симметричный отступ в инлайн-направлении (обычно «слева и справа») | Центрирование контейнера без физических `margin-left/right`            | `layout/_container.scss`           |
| `padding-inline`   | Отступы внутри элемента по инлайн-направлению                      | Адаптивные внутренние отступы, совместимые с RTL                       | `layout/_container.scss`, `header` |
| `gap`              | Промежуток между flex/grid-элементами                              | Безопасный отступ без схлопывания, не влияет на размер контейнера      | `header`, `buttons`, `layout`      |


## Цвет и фон

| Свойство           | Общее значение     | Зачем в проекте                              | Где используется                         |
|--------------------|--------------------|----------------------------------------------|------------------------------------------|
| `color`            | Цвет текста        | Семантические цвета из дизайн-системы        | Везде                                    |
| `background-color` | Цвет фона элемента | Фон хедера, кнопок, тела страницы            | `header`, `buttons`, `body`              |
| `fill`             | Цвет заливки SVG   | Унификация цвета иконок через `currentcolor` | `base.scss` (автоматически для всех SVG) |
| `stroke`           | Цвет обводки SVG   | То же для обводок                            | `base.scss`                              |


## Интерактив и состояния

| Свойство                  | Общее значение                             | Зачем в проекте                                               | Где используется                                            |
|---------------------------|--------------------------------------------|---------------------------------------------------------------|-------------------------------------------------------------|
| `transition`              | Плавное изменение свойств во времени       | Улучшает восприятие интерфейса                                | `globals.scss` (универсальный для `a`, `button` и др.)      |
| `transform`               | Преобразует элемент (сдвиг, поворот и др.) | Эффект «нажатия» (`translateY`) и центрирование (`translate`) | `mixins/press-down`, `abs-center`                           |
| `:hover`                  | Состояние при наведении курсора            | Визуальная обратная связь на десктопе                         | `header`, `buttons`                                         |
| `:active`                 | Состояние при нажатии                      | Обратная связь на тач-устройствах                             | Оборачивается в `@media (hover: none)` через миксин `hover` |
| `:focus-visible`          | Фокус только при клавиатурной навигации    | Доступность: фокус не мешает при клике мышью                  | `mixins/focus-outline-rounded`                              |


## Позиционирование и layout

| Свойство                      | Общее значение                                                                       | Зачем в проекте                                                                                   | Где используется                     |
|-------------------------------|--------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|--------------------------------------|
| `display: block` (избыточное) | Часто не нужно, если элемент: а) абсолютно позиционирован, б) внутри flex/grid       | Упрощает код, убирает дублирование, повышает читаемость                                           | Псевдоэлементы, иконки, бейджи       |
| `display: flex`               | Flexbox-контейнер                                                                    | Гибкое выравнивание и распределение                                                               | Везде: `header`, `buttons`, `layout` |
| `display: inline-flex`        | Контроль размеров интерактивных элементов без разрыва строки                         | Контроль размеров интерактивных элементов без разрыва строки                                      | `button-base`, ссылки                |
| `justify-content`             | Распределение элементов по главной оси                                               | Выравнивание: `space-between`, `center`                                                           | `header`, `buttons`                  |
| `align-items`                 | Выравнивание по поперечной оси                                                       | Вертикальное центрирование                                                                        | Везде                                |
| `position: absolute`          | Абсолютное позиционирование                                                          | Точный контроль над положением                                                                    | `abs-center` (редко)                 |
| `min-height`                  | Устанавливает минимальную высоту элемента                                            | Гарантирует, что layout занимает как минимум всю высоту viewport (для «прижатого» футера)         | `.app`                               |
| `dvh`                         | Dynamic viewport height — адаптируется под видимую высоту (с учётом адресной строки) | Предотвращает «прыжки» и лишний скролл на мобильных при full-height layout                        | `layout/_app.scss`                   |
| `flex`                        | Сокращение для `flex-grow`, `flex-shrink`, `flex-basis`                              | Позволяет `.main-layout` растягиваться и заполнять доступное пространство между шапкой и подвалом | `.main-layout`                       |
| `max-width`                   | Ограничивает максимальную ширину элемента                                            | Центрирует и ограничивает ширину контента на больших экранах (1200px)                             | `.container`                         |

### Контентно-управляемые размеры
| Свойство / значение  | Общее значение                   | Зачем в про екте                                          | Где может использова ться                |
|----------------------|----------------------------------|-----------------------------------------------------------|------------------------------------------|
| `width: min-content` | Ширина по самому длинному слову  | Экономия места для компактных элементов (бейджи, иконки)  | Бейджи, теги, мобильные элементы         |
| `width: fit-content` | Ширина по контенту с переносами  | Адаптивные кнопки и карточки без фиксированной ширины     | Кнопки, модальные окна, карточки товаров |
| `width: max-content` | Ширина по контенту без переносов | Только если точно известно, что текст короткий            | Заголовки (с осторожностью!)             |


## Доступность и UX

| Свойство                      | Общее значение                                                       | Зачем в проекте                                                                              | Где используется                               |
|-------------------------------|----------------------------------------------------------------------|----------------------------------------------------------------------------------------------|------------------------------------------------|
| `clip-path`                   | Обрезает элемент по заданной форме                                   | Скрывает текст визуально, но оставляет для скринридеров (вместе с `position: absolute`)      | `utilities.scss` (`.visually-hidden`)          |
| `white-space: nowrap`         | Запрещает перенос строк                                              | Сохраняет компактность навигационных ссылок и кнопок                                         | `header`, `buttons`                            |
| `overflow: hidden`            | Скрывает вылезающий контент                                          | Визуальная чистота                                                                           | `.visually-hidden`, `img`                      |
| `cursor: pointer`             | Меняет курсор на «руку»                                              | Визуальный сигнал кликабельности                                                             | `buttons`, `label`                             |
| `margin-bottom`               | Отступ снизу элемента                                                | Добавляет пространство под параграфами (до логической замены на `margin-block-end`)          | `base.scss` (внутри `:where`)                  |
| `font`                        | Сокращённое свойство для всего шрифта (семейство, размер, вес и др.) | Позволяет всем полям ввода и кнопкам наследовать стили текста от body                        | `base.scss` (`input`, `button` и др.)          |
| `-webkit-tap-highlight-color` | Цвет подсветки при тапе на iOS/Android                               | Убирает серую «вспышку» при нажатии на кнопки на мобильных                                   | `base.scss`                                    |
| `border-color`                | Задаёт цвет границы таблицы                                          | Унифицирует цвет границ таблиц через `currentcolor` (наследует цвет текста)                  | `base.scss` (`table`)                          |
| `outline`                     | Контур вокруг элемента (не влияет на layout)                         | Используется в debug-режиме для визуальной отладки структуры                                 | `globals.scss` (закомментировано по умолчанию) |
| `box-sizing`                  | Определяет, как рассчитываются ширина и высота элемента              | `border-box` включает padding и border в заданную ширину/высоту — предотвращает переполнение | `reset.scss` (глобально для всех элементов)    |
| `font-style`                  | Задаёт начертание текста (курсив и т.д.)                             | Нормализует стиль адреса, убирая курсив по умолчанию                                         | `reset.scss` (`address`)                       |
| `scrollbar-gutter`            | Резервирует пространство для скроллбара                              | Предотвращает «прыжок» макета при появлении/исчезновении вертикального скролла               | `modern.scss`                                  |
| `scroll-behavior`             | Управляет плавностью прокрутки                                       | Делает якорные переходы плавными (улучшает UX)                                               | `modern.scss`                                  |
| `animation-duration`          | Длительность CSS-анимации                                            | Принудительно сокращает анимации до 0.01ms при `prefers-reduced-motion`                      | `modern.scss`                                  |
| `animation-iteration-count`   | Количество повторов анимации                                         | Ограничивает анимацию одним циклом при `prefers-reduced-motion`                              | `modern.scss`                                  |
| `box-shadow`                  | Добавляет тень вокруг элемента                                       | Создаёт фокус-контур с закруглением без влияния на layout                                    | `mixins.scss` (`focus-outline-rounded`)        |
| `aspect-ratio`                | Задаёт соотношение сторон элемента                                   | Позволяет создавать квадраты и пропорциональные блоки без JavaScript или padding-хаков       | `mixins.scss` (`square`)                       |


## Современные улучшения

| Свойство                   | Общее значение                       | Зачем в проекте                                     | Где используется |
|----------------------------|--------------------------------------|-----------------------------------------------------|------------------|
| `scrollbar-gutter: stable` | Резервирует место под скроллбар      | Предотвращает «прыжок» макета при появлении скролла | `modern.scss`    |
| `scroll-behavior: smooth`  | Плавная прокрутка                    | Улучшает UX при якорных ссылках                     | `modern.scss`    |
| `backdrop-filter: blur()`  | Размытие фона за элементом           | «Стеклянный» эффект хедера                          | `header`         |
| `prefers-reduced-motion`   | Медиа-запрос для отключения анимаций | Уважение к предпочтениям пользователя               | `modern.scss`    |
