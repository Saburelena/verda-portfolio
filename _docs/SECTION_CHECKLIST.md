# SECTION VERIFICATION CHECKLIST

Чек-лист для проверки каждой новой секции после вёрстки.  
Используй перед коммитом (`Ctrl + K`) и перед показом ментору.

---

## Типографика и текст

- [ ] Все заголовки (`h1–h4`, `.h1–.h4`) используют `text-wrap: balance`  
  → Проверь на экранах **700–900px** в DevTools (`Ctrl + Shift + I`)
- [ ] Нет `<br>` для переноса строк — используй CSS или семантические блоки
- [ ] Все абзацы — через `<p>`, а не `<div>`
- [ ] Для длинных текстов — `line-height: 1.5–1.6`

## Семантика и доступность (a11y)

- [ ] Картинки имеют `alt`:
    - содержательный — если несёт смысл (`alt="Verda logo"`),
    - пустой — если декоративная (`alt=""`)
- [ ] Секции с контентом используют `<section aria-labelledby="id">` + `<h2 id="id">`
- [ ] Все интерактивные элементы:
    - имеют `:focus-visible` (через миксин `focus-outline-rounded`),
    - работают с клавиатуры (Tab / Enter)
- [ ] Нет `div` вместо кнопок или ссылок

## Layout и позиционирование

- [ ] Для блочных контейнеров с единственным дочерним элементом → использовать `display: grid; place-items: center;` вместо `display: flex + justify-content/align-items` 
  → Не `display: flex; justify-content + align-items` (если только не несколько элементов)
- [ ] Используются **логические свойства**:
    - `margin-inline`, `padding-inline`, `margin-block-end`
    - вместо `margin-left/right`, `padding-left/right`
- [ ] Размеры по контенту → `width: min-content` / `fit-content` (не хардкод через `width: 120px`)
- [ ] Высота viewport → `100dvh`, а не `100vh`  
  → Используй `@supports (min-height: 100dvh)` для fallback (см. `layout/_app.scss`)

## Интерактив и состояния

- [ ] Все кнопки и ссылки используют миксин `press-down` для эффекта нажатия
- [ ] Навигационные ссылки — через `reset-link`
- [ ] При наведении на десктопе — `:hover`, на мобильных — `:active` (через миксин `hover`)
- [ ] Нет `cursor: pointer` на неинтерактивных элементах

## Адаптивность и медиа

- [ ] Используются медиа-миксины из `media.scss`:
    - `@include mobile-only { ... }`
    - `@include tablet-up { ... }`
- [ ] Изображения — адаптивные:
  ```html
  <img src="..." loading="lazy" width="..." height="...">
  
Нет фиксированных px там, где можно использовать rem или %

## Чистота кода
- Нет избыточного display: block:
  - у ::before/::after с position: absolute,
  - у детей flex/grid-контейнеров
- Все SCSS-переменные — из variables/_*.scss, а не «голые» значения 
- Нет дублирования стилей — используется БЭМ и миксины
